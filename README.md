# Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end **Data Analytics workflow**, starting from dataset loading and data exploration in Python to SQL analysis, Power BI dashboard development, and business reporting.

The main objective is to clean and analyze the data, identify meaningful patterns and insights, and present the findings through interactive visualizations and reports.

## 🔄 Project Steps

### 1. Load Dataset

The dataset is loaded into Python using Pandas.

Key activities:

* Import dataset
* Review rows and columns
* Check dataset shape
* Understand column names
* Inspect data types

### 2. Exploratory Data Analysis (EDA)

EDA was performed to understand the dataset and identify important patterns.

Activities include:

* Descriptive statistics
* Missing value analysis
* Duplicate value detection
* Data distribution analysis
* Identifying outliers
* Finding relationships between variables
* Creating visualizations

### 3. Data Cleaning

The dataset was cleaned and prepared for further analysis.

Cleaning activities:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Removing unnecessary columns
* Standardizing text values
* Handling inconsistent data
* Checking data quality

### 4. PostgreSQL & SQL Analysis

The cleaned dataset was imported into **PostgreSQL** for structured data analysis.

SQL analysis includes:

* Filtering data using `WHERE`
* Aggregating data using `GROUP BY`
* Filtering aggregated results using `HAVING`
* Sorting results using `ORDER BY`
* Using `JOIN` operations
* Using aggregate functions such as `SUM()`, `AVG()`, `COUNT()`, `MIN()`, and `MAX()`
* Creating business-focused analytical queries

### 5. Power BI Dashboard

The analyzed data was connected to **Power BI** to create an interactive dashboard.

Dashboard components include:

* KPI cards
* Charts and graphs
* Category-wise analysis
* Trend analysis
* Filters and slicers
* Summary of important business metrics

The dashboard helps users quickly understand the key findings and trends in the data.

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### Step 2: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 3: Open Jupyter Notebook

```bash
jupyter notebook
```

Open the project notebook and run the Python cells step by step.

* Create a database
